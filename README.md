# AI Identity Security Capstone

## Overview

This repository contains the AI Identity Security Capstone, covering threat modeling, IAM design, red-team testing, blue-team hardening, policy, compliance mapping, and security recommendations.

## Project Structure

| Folder | Project | Description |
|---|---|---|
| 01-threat-model | Project 1 | AI identity threat modeling and risk assessment |
| 02-iam-design | Project 2 | IAM architecture, authentication, authorization and access controls |
| 03-red-team | Project 3 | Adversarial testing and attack findings |
| 04-blue-team | Project 4 | Guardrails, hardening, token security and anomaly detection |
| 05-policy | Project 5 | AI identity security policy and compliance mapping |

## Key Security Controls

- Least-privilege access
- Role-Based Access Control (RBAC)
- Secure authentication and authorization
- JWT protection and redaction
- Refresh token replay detection
- Key rotation and signature validation
- Anomaly detection
- AI security guardrails
- Compliance mapping and incident response
